# /remote-sendell — short form

After one-time install (`node scripts/install-remote-sendell.mjs --hub <HUB> --project <YOUR_PROJECT>`):

In Grok, type **only** the code from **this** phone room (never an old sample):

```text
rc THE_CODE_SHOWN_ON_THE_PHONE
```

Quiet: after pair say only `rc on`. Phone text = normal user message. `reply` answer-only.

Config lives in `~/.sendell/config.json` (hub + script path on **this** machine).
